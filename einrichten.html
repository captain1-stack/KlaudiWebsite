Für wen richten wir Klaudi ein?

Die Einrichtung dauert nur etwa drei Minuten.

Wen darf Klaudi regelmäßig anrufen?

Die Einrichtung dauert etwa drei Minuten. Wir gehen alles gemeinsam Schritt für Schritt durch.

Bitte tragen Sie den Vornamen ein.

Sie können alle Angaben später jederzeit ändern.

Unter welcher Telefonnummer erreicht Klaudi diese Person?

Klaudi ruft auf dem normalen Festnetz oder Handy an. Es wird keine App benötigt.

Bitte tragen Sie eine gültige Telefonnummer ein.

☎ Klaudi ruft immer von derselben Telefonnummer an. So kann die Person den Anruf leicht wiedererkennen.

Die Telefonnummer wird nur für die vereinbarten Anrufe verwendet.

Wie oft soll Klaudi anrufen?

Sie können das später jederzeit ändern oder pausieren.
